IconButton — square, icon-only control for menus, close, send, table row actions.

```jsx
<IconButton icon="menu" label="Open menu" />
<IconButton icon="send" label="Send" variant="primary" />
<IconButton icon="pencil" label="Edit" variant="outline" size="sm" />
```

- ghost by default (muted → deep blue on hover); outline for toolbars; primary for the chat send button.
- `active` = gold wash + gold border (selection state).
